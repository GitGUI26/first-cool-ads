Before you boot

This is experimental. Android-x86 4.4 is a desktop build from 2014, not a phone. There is no Google Play, no Play Services, and no modern app support.

  • First boot is slow: the image is streamed on demand and the kernel log can scroll for several minutes.
  • Click the screen to capture the mouse. Press Esc to release it.
  • Use the on-screen controls to pause, restart, or go fullscreen.
  • Network access inside Android is not configured. Local apps and the built-in browser still work.

Android-x86 is an independent open-source project. v86 is BSD-2-Clause licensed. The Android image is streamed from the public v86 demo cache, with an automatic mirror fallback; no ROMs or personal files leave this browser.
